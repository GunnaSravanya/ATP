# React UI Components Project

A frontend project developed using React and Tailwind CSS to demonstrate reusable components, responsive layouts, props handling, and dynamic rendering of data.

---

# Technologies Used

- React
- Tailwind CSS
- JavaScript
- HTML
- CSS

---

# Project Features

## Responsive Navigation Bar
- Displays menu items such as Home, About Us, and Login
- Built using Flexbox for responsive alignment
- Styled using Tailwind CSS utility classes

---

## Dynamic User Cards
- User details are rendered dynamically from an array
- Each card contains:
  - Profile Image
  - User Name
  - User Email
- Responsive grid layout for better UI experience

---

## Product Cards
- Product information displayed using reusable components
- Each product card includes:
  - Product Title
  - Product Price
  - Product Description
- Data passed through props for component reusability

---

## Reusable Components
- Components are separated for better code organization
- Improves readability and maintainability
- Reduces code duplication

---

## Responsive Design
- Grid layouts automatically adjust for:
  - Mobile devices
  - Tablets
  - Large screens
- Implemented using Tailwind CSS responsive classes

---

## Footer Section
- Contains:
  - Product Links
  - Feature Links
  - Contact Information
- Structured using responsive grid layout

---

# React Concepts Used

- Functional Components

- Component Reusability
- Responsive UI Design
